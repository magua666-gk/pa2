MASAC / SAC 训练与测试命令（所有模式）
项目根目录（Windows）：d:\pa2\path planning2

============================================================
0）基础说明
============================================================
所有命令均从项目根目录执行：
cd "d:\pa2\path planning2"
主入口脚本：
python main_SAC_curriculum.py
若路径中包含空格，模型路径需用英文引号包裹。
测试时智能体数量尽量与训练时保持一致。
conda activate uav


============================================================
1）训练：课程学习
============================================================

1.1 课程学习 + 注意力机制（单次运行）
python main_SAC_curriculum.py --use_curriculum

1.2 课程学习 + 无注意力机制（对比实验）
python main_SAC_curriculum.py --use_curriculum --disable_attention

1.3 课程学习 + 注意力机制（固定种子多次运行）
python main_SAC_curriculum.py --use_curriculum --multi_run --num_runs 3 --seeds 42,123,456

1.4 课程学习 + 无注意力机制（固定种子多次运行）
python main_SAC_curriculum.py --use_curriculum --disable_attention --multi_run --num_runs 3 --seeds 42,123,456

1.5 课程学习 + 注意力机制（随机种子多次运行）
python main_SAC_curriculum.py --use_curriculum --multi_run --num_runs 3 --random_seed


============================================================
2) 训练：无课程学习（MASAC 后端）
============================================================

2.1 无课程学习 + 注意力机制 MASAC（默认后端）
python main_SAC_curriculum.py --no_curriculum_backend attention_masac --train_episodes 500 --save_interval 100 --hero_count 1 --enemy_count 1 --obstacle_count 1

2.2 无课程学习 + 注意力机制 MASAC + 共享跟随者策略
python main_SAC_curriculum.py --no_curriculum_backend attention_masac --share_follower_policy_no_curriculum --train_episodes 500 --save_interval 100 --hero_count 1 --enemy_count 1 --obstacle_count 1

2.3 无课程学习 + 无注意力机制 MASAC（对比实验）
python main_SAC_curriculum.py --no_curriculum_backend attention_masac --disable_attention --train_episodes 500 --save_interval 100 --hero_count 1 --enemy_count 1 --obstacle_count 1

2.4 无课程学习 + 注意力机制 MASAC + 自定义输出标签 / 根目录
python main_SAC_curriculum.py --no_curriculum_backend attention_masac --ablation_tag attention_no_curriculum_expA --ablation_output_root "d:\pa2\path planning2" --train_episodes 500 --save_interval 100 --hero_count 1 --enemy_count 1 --obstacle_count 1

============================================================
6) 结果 / 工具命令
============================================================

6.1 生成测试结果索引

6.4 强制使用自定义结果根目录（覆盖默认路径）
python main_SAC_curriculum.py --results_dir "d:\pa2\path planning2\results\manual_results_root" --test --model_path "models/final/final_model"

============================================================
8) GAT (图注意力机制) 专用命令
============================================================
说明：使用 GAT 机制时，必须在训练和测试命令中都加上 `--gat` 参数，以确保网络结构正确实例化并加载相应的权重。

8.1 训练：课程学习 + GAT 机制
python main_SAC_curriculum.py --use_curriculum --gat

8.2 训练：无课程学习 + GAT 机制
python main_SAC_curriculum.py --no_curriculum_backend attention_masac --gat --train_episodes 500 --save_interval 100 --hero_count 1 --enemy_count 1 --obstacle_count 1

8.3 测试：单一难度 + GAT 模型
python main_SAC_curriculum.py --test --gat --model_path "models/你的GAT模型路径/final_model" --hero_count 1 --enemy_count 1 --obstacle_count 1 --test_episodes 100

8.4 测试：多难度测试 + GAT 模型
python main_SAC_curriculum.py --multi_difficulty_test --gat --model_path "models/你的GAT模型路径/final_model" --hero_count 1 --enemy_count 1 --test_episodes 100 --max_obstacle 5 --step_size 1

8.5 快速验证：GAT 机制训练与测试
# 快速训练10个回合
python main_SAC_curriculum.py --no_curriculum_backend attention_masac --gat --train_episodes 10 --save_interval 5 --hero_count 1 --enemy_count 1 --obstacle_count 1
# 快速测试（带渲染观看效果）
python main_SAC_curriculum.py --test --gat --model_path "models/你的GAT模型路径/final_model" --hero_count 1 --enemy_count 1 --obstacle_count 1 --test_episodes 5 --render
